# Scheme I/O capture handlers for the RTE-RRTMGP objects (xdsl_ccpp
# --capture-ddt-handlers; format: xdsl_ccpp.util.capture_ddt_handlers).
# The routines are in ccpp_capture_rte_objects.F90, compiled only into
# capture builds and their test drivers. ccpp_netcdf_reader.F90 (a
# plain-NetCDF ccpp_io_reader, for scheme inits that read a file, such as
# the RRTMGP gas optics) goes into the test drivers only: the model has
# PIO's. device_enter/device_exit keep an object on the device across a
# GPU test driver's call of a scheme whose own OpenACC names it, as in a
# production run with resident data. Design notes:
# capture_rte_objects_plan.md.
